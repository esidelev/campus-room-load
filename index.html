Load through the day

How load is measured. A building's denominator is the number of its rooms that appear in any of the three terms' schedules — 204 rooms in all, so the terms compare on the same base. Rooms that never host a class don't exist in this data, so a building with unscheduled space will read as busier than it is. Online, off-campus, and to-be-announced sections are excluded; cancelled sections are dropped, classes with several instructors are counted once, and cross-listed sections sharing a room are shown together. Exact enrollment figures are not included in this version. Events. Spring 2026 also carries room reservations from the events calendar. They are dated bookings, not weekly patterns, so a slot is shown only where the same room, time and event repeat in at least three different weeks — 321 one-off bookings are left out. Turn events off to see classes alone. Size bands use each section's own enrolled headcount, so two cross-listed sections sharing a room are banded separately rather than combined. Building positions are schematic, not survey-accurate.
