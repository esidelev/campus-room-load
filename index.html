How load is measured. A building's denominator is the number of its rooms that appear in either term's schedule — 191 rooms in all, so the two terms compare on the same base. Rooms that never host a class don't exist in this data, so a building with unscheduled space will read as busier than it is. Online, off-campus, and to-be-announced sections are excluded; cancelled sections are dropped, classes with several instructors are counted once, and cross-listed sections sharing a room are shown together. Enrollment figures are not included in this version. Building positions are schematic, not survey-accurate.
